# 🎯 Habit Flow — Ultimate Habit Tracking Web App

**Your personalized habit tracker. Build consistency, track streaks, celebrate progress.**

---

## 📋 Problem Statement

Forming habits is hard. Tracking them shouldn't be.

Most habit trackers are either:
- Too complex (overkill for simple tracking)
- Too simple (no motivation mechanics)
- Expensive (requires subscription)

**Habit Flow** solves this: Free, simple, powerful habit tracking with streak mechanics that actually motivate you.

---

## ✨ Key Features

- ✅ **Create & Track Habits** — Set daily habits and mark them complete
- 🔥 **Streak Tracking** — Watch your streak grow (motivation is real!)
- 📊 **Progress Analytics** — Visualize your habit completion rate
- 🔔 **Smart Reminders** — Get notified before you forget
- 💾 **Persistent Storage** — Your data never disappears (stored locally)
- 📱 **Fully Responsive** — Works perfectly on mobile, tablet, desktop
- ⚡ **Zero Backend** — Runs 100% in your browser (super fast)
- 🔓 **Open Source** — No hidden tracking, your data is yours

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Storage:** Browser LocalStorage API
- **Deployment:** GitHub Pages (free hosting)
- **Design:** Responsive CSS Grid & Flexbox

## 📸 Features in Action

### Create a Habit
Simply type your habit (e.g., "Read 30 minutes") and press Enter. It's saved instantly.

### Track Daily
Mark habits complete each day. Your streak counter updates in real-time.

### Visualize Progress
See your completion percentage for the month. Consistency = motivation.

### Smart Reminders
Get notified if you're about to break your streak (coming soon).
