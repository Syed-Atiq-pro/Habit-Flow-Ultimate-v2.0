# 🔥 Habit Flow — Daily Habit Tracker

A motivational habit-tracking web app that helps users build 
discipline through streaks, daily check-ins, and progress feedback.

## 🚀 Live Demo
👉 [Open App](https://Syed-atiq-pro.github.io/Habit-Flow-Ultimate-v2.0)

## ✨ Features
- ✅ Add and track daily habits
- 🔥 Streak counter to keep you motivated
- 📊 Real-time completion tracking
- ⏰ Reminder logic for consistency
- 📱 Fully responsive — works on mobile & desktop
- ⚡ Zero backend — runs entirely in the browser

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (ES6+)
- Deployed via GitHub Pages

## 📸 How to Use
1. Open the live app
2. Add your daily habits
3. Check them off each day
4. Watch your streak grow!
